WR3 – Introduction to Networking

Project Description

This project is a simple Python script that uses the socket module to resolve a hostname into an IP address and prints a short greeting with the result.

HOW TO RUN

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:
   
   python networking.py
